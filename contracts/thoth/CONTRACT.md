# Thoth <-> NAVI Contract

## Thoth -> NAVI

Provides authorized historical context, memory summaries, prior dispositions, verified outcomes, temporal anchors, and durable evidence references.

NAVI treats Thoth context as historical evidence, not unquestionable truth. Conflicts with current evidence are surfaced as contradictions.

## NAVI -> Thoth

Writes only governed analytical summaries, detector calibration outcomes, resolved pattern history, and references to executive/verification/proof artifacts.

Raw transient detector noise should not be promoted into durable memory by default.

## Required fields

`contract_version`, `message_id`, `correlation_id`, `memory_record_ids`, `time_window`, `security_classification`, `evidence_refs`, `disposition_refs`, `proof_refs`.

## Boundary

Thoth is memory cortex; NAVI is recognition. NAVI does not replace memory ownership, and Thoth does not convert stored patterns into execution authority.
