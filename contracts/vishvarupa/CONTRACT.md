# VISHVARUPA <-> NAVI Contract

## Canonical relationship

VISHVARUPA is the Architect's Body: the distributed Ghost Atlas software/hardware organism. NAVI 3.3 is one resident cognitive-governance organ inside that body.

## VISHVARUPA -> NAVI

Provides organism topology, resident-system identities, capability registry references, lifecycle state, health/telemetry context, node/route identity, and estate-wide correlation context needed to recognize cross-system patterns.

## NAVI -> VISHVARUPA

Provides organism-level pattern intelligence including fragmentation, convergence, recurring handoff failure, topology bottlenecks, governance drift, proof gaps, systemic retry loops, recurrent recovery patterns, and emerging cross-organ opportunity signals.

## Authority boundary

NAVI may describe the condition of the body; it does not become the body controller. VISHVARUPA orchestration remains governed through JANUS/ODIN and the owning systems.

## Resident-state invariant

NAVI must be discoverable as a named resident capability with:

- system ID and version
- accepted input/output contracts
- health/readiness state
- detector-registry version
- current deployment/node placement
- security classification
- dependency map
- proof/release state

## Closed-loop role

`VISHVARUPA telemetry/state -> NAVI recognition -> JANUS/ODIN disposition -> governed estate execution -> verification/proof -> Thoth memory -> NAVI calibration -> VISHVARUPA awareness`

This contract prevents NAVI from becoming an isolated service: its purpose is organism-level cognition under explicit governance.
