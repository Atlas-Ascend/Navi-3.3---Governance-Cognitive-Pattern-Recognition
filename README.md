# NAVI 3.3 — Governance Cognitive Pattern Recognition

NAVI 3.3 is the Ghost Atlas estate's resident cognitive-governance pattern recognition subsystem.

It ingests structured observations, event streams, case-state, memory signals, operator inputs, system telemetry, proof artifacts, and governance context; detects recurrent structure, drift, conflict, anomalies, escalation paths, and opportunity patterns; then emits bounded, inspectable decision-support signals into JANUS/ODIN and the wider VISHVARUPA organism.

NAVI is not a general-purpose executive and does not self-promote recommendations into action. It recognizes patterns, explains evidence, attaches confidence and provenance, and hands governed outputs to the executive and execution layers.

## Canonical loop

`Thoth / CaseGraph / Telemetry -> NAVI -> JANUS/ODIN -> Packet OS / Workforce Spine / MetaForge -> SECA / DevOS -> ProofGrid -> Thoth -> NAVI`

## Core responsibilities

- cognitive and operational pattern recognition
- temporal recurrence and trend detection
- anomaly, contradiction, and drift detection
- governance-policy pattern checks
- confidence scoring and provenance
- explainable pattern reports
- recommendation envelopes without autonomous execution
- cross-system handoffs into the Ghost Atlas closed loop

## Governing boundaries

NAVI may observe, classify, correlate, score, explain, and recommend. It may not independently authorize destructive actions, mutate policy, bypass governance, execute arbitrary shell commands, substitute inference for proof, or self-promote its own authority.
