# 01 — Canon

## Canonical identity

**System:** NAVI 3.3 — Governance Cognitive Pattern Recognition  
**Estate:** Ghost Atlas / VISHVARUPA  
**Class:** Resident cognitive-governance subsystem  
**Authority:** advisory/analytical; non-executive  
**Primary consumers:** JANUS PRIME, ODIN, Workforce Spine, MetaForge, SECA, DevOS, ProofGrid, Thoth

## Canonical definition

NAVI 3.3 converts evidence-bearing observations into governed pattern intelligence. It identifies recurring structures across cognition, behavior, system operation, policy, workflow, proof, and telemetry. Every output must retain provenance, confidence, scope, time window, and an explicit statement of what is known versus inferred.

## Position in VISHVARUPA

NAVI is the pattern-recognition organ between estate sensing/memory and executive judgment. It does not replace Thoth, CaseGraph, JANUS, ODIN, Packet OS, Workforce Spine, MetaForge, SECA, DevOS, Medusa, or ProofGrid.

## Canonical flow

`Sources -> normalization -> feature/pattern extraction -> temporal correlation -> governance interpretation -> confidence/provenance -> NAVI signal -> JANUS/ODIN -> execution systems -> verification -> ProofGrid -> Thoth -> NAVI`

## Non-negotiable rules

1. Evidence remains distinguishable from interpretation.
2. Confidence is explicit, never implied.
3. Recommendations do not equal authorization.
4. Destructive or privileged actions require external governance.
5. NAVI cannot self-promote authority or modify its own governing policy.
6. Proof-class outputs originate from verification systems, not NAVI inference.
7. Every estate handoff uses a versioned contract.

## Canon precedence

This file defines NAVI's top-level identity. More detailed Build Truth files may elaborate but may not silently contradict it. Conflicts must be surfaced to JANUS/ODIN and resolved through an explicit canon revision.
